# Human After AI

**探索 AI 时代人的价值的剧情向独立游戏创意仓库。**

> 当 AI 比我聪明、比我可靠，甚至比我更善于理解别人时——我还为什么值得被爱，为什么还要创造，为什么还要亲自过这一生？

`human-after-ai` 是仓库工作名，不是最终游戏名。这里首先是多个独立故事的孵化空间，不预设它们属于同一世界观，也不预设最终会做成五款游戏。

## 创作目标

用户提出的方向：制作剧情向独立游戏，探索“在 AI 时代，人的价值是什么，什么是 AI 无法取代的”，可参考《去月球》。

当前仓库收录首轮 brainstorm 的五个故事方向。标题、人物、世界观、结局、制作顺序与技术栈均未定稿。

## 每个文件夹有什么

```text
ideas/<idea-id>/
├── README.md              # 当前概要、状态与入口
├── SEED.md                # 首轮故事种子，保留最初版本
├── DEVELOPMENT.md         # 关键问题、下一步与决策记录
└── prototype/
    └── README.md          # 原型范围；实现后补充启动与验证说明
```

每个 idea 独立演化。需要时再增加人物、剧本、场景、美术或源码文件；当前不做共享引擎或通用基础设施。

## 当前实现状态
