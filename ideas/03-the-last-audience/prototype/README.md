# 《最后一位观众》原型入口

**当前状态：尚无可运行原型，未选择引擎。**

## 首个切片候选

一段短戏、两次排练、一次旧友来访，以及一次是否保留私人台词的决定。只测试修改如何改变表达对象。

候选试玩长度为 15–20 分钟，仅用来控制设计范围，不是工期或实现承诺。先用纸面、对白表或静态交互验证；技术选择服从叙事需要。

## 原型需要验证

- [ ] 玩家能指出自己改动的一句台词怎样改变了某个人的理解。
- [ ] AI 的至少一个修改真正有帮助；原稿和修改稿都不是固定的道德正确答案。
- [ ] AI 的观众身份来自前面可见的行动，不靠结尾突然宣告。

## 本阶段不做

不搭通用游戏引擎，不做开放世界，不接实时大模型，不做账号、云服务、付费、素材流水线或完整存档系统。临时素材可用占位文字和简单形状；正式外部素材需记录来源与使用条件。
