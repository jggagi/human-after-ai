# 《明天我会来》原型入口

**当前状态：尚无可运行原型，未选择引擎。**

## 首个切片候选

一次邀请、一次委托选择、一次事后重逢。只用一个社区场景和三位角色，不先模拟几年的人生。

候选试玩长度为 15–20 分钟，仅用来控制设计范围，不是工期或实现承诺。先用纸面、对白表或静态交互验证；技术选择服从叙事需要。

## 原型需要验证

- [ ] 玩家在选择时能说出委托的真实好处，而不是立即识别为坏结局按钮。
- [ ] 重逢通过具体关系事实改变玩家的理解，而不是播放“你缺席了”的训诫。
- [ ] AI 与被陪伴者拥有自己的意愿；没有删除 AI、使 AI 故障或强制其退出的解法。

## 本阶段不做

不搭通用游戏引擎，不做开放世界，不接实时大模型，不做账号、云服务、付费、素材流水线或完整存档系统。临时素材可用占位文字和简单形状；正式外部素材需记录来源与使用条件。

## 开始实现时补充
