# 《请不要替我原谅》原型入口

**当前状态：尚无可运行原型，未选择引擎。**

## 首个切片候选

一间旧居、三件有明确来源的资料、一场重构对话，以及一次是否向现实中的家人发消息的决定。

候选试玩长度为 15–20 分钟，仅用来控制设计范围，不是工期或实现承诺。先用纸面、对白表或静态交互验证；技术选择服从叙事需要。

## 原型需要验证

- [ ] 玩家能分清一条真实记录、一项推测与一次新表达。
- [ ] 客户的安慰被认真承认，但没有被包装成死者真实作出的原谅。
- [ ] 资料并不组成一个全知答案；至少一处不确定性被保留。

## 本阶段不做

不搭通用游戏引擎，不做开放世界，不接实时大模型，不做账号、云服务、付费、素材流水线或完整存档系统。临时素材可用占位文字和简单形状；正式外部素材需记录来源与使用条件。
