# 《无用之城》· 最后两份记录

状态：故事与交互提案；已实际运行的独立网页 demo。人物、剧情与主题表达仍待玩家验证，不表示作者已定稿。

创意与源码：<https://github.com/jggagi/human-after-ai/tree/main/ideas/05-city-without-use>。网页源码保存在对应的 `prototype/` 目录，原始故事快照 `SEED.md` 保留。

玩家扮演职业介绍员周行。AI 接手许多岗位以后，居民的住房和生活仍有保障，介绍所将在周五结束职业业务。周行想在关门前回应最后两位来访者：许立想继续工作、被人需要，丁禾却不想求职。周行习惯用“找到下一份工作”判断是否帮到了人，自己的下一份工作也仍空着。

## 本轮改动

上一版把太多选择放在贴标签、摆桌、排时段和移交上，人物的愿望与损失没有成为主线。本轮以三个必经冲突取代琐事链：许立准备开门，借用需求却已被自动服务完成；丁禾质疑自己为何仍被标为“未安置”；周行面对自己的岗位结束，问出“没人来找我，我还算什么”。

主题通过人物处境和后果表达：工作不再是生存的必要条件时，人是否也能允许自己暂时不被需要。继续工作、休息或联系一个熟悉的人均可选择，故事不按就业率或幸福分数评判。

## 可玩范围

- 依次介绍玩家、两位来访者与 AI 同事，随时查看人物背景和关系。
- 三个开场了解角度、两组可选追问。
- 三种回应许立的方式：试办一个上午、先试两小时，或继续寻找真实岗位。确认前可改谈，不虚构需求以制造依赖。
- 三种回应丁禾的方式。继续推荐会遇到明确拒绝，周行随之停止匹配；不把不求职当成失败。
- 三个关于周行以后的选择：继续求职、暂时休息、与澄约一次不带待办的谈话。
- 次日反馈、随选择变化的结尾、工作记录、谈话回看、物件观察、键盘操作、雨声开关和重玩。

## 本地运行

游戏无需安装依赖。使用 Python 3，在本目录运行：

```sh
python3 -m http.server 4173 --directory dist --bind 0.0.0.0
```

访问 `http://localhost:4173`，也可以直接打开 `dist/index.html`。试玩页使用 Sites 保持现有私有访问范围：<https://city-without-use-demo.jggagi.chatgpt.site>。

## 验证

`tests.mjs` 为可选浏览器验证脚本，需要 Node.js、Playwright 和 Chromium；游戏运行不依赖它们。已有这些工具的环境可以运行 `node tests.mjs`。也可通过 `CITY_PLAYWRIGHT_MODULE` 指向已有 Playwright 模块，通过 `CITY_CHROMIUM_PATH` 指向已有浏览器，不需要修改源码。

本次使用环境已有工具，启动本地服务后运行：

```sh
CITY_PLAYWRIGHT_MODULE=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright/index.mjs CITY_CHROMIUM_PATH=/usr/bin/chromium node tests.mjs
```

实际验证结果见 `VALIDATION.md`。

## 素材与限制

`dist/assets/office.webp` 为本次生成的原创场景图，由 PNG 转换为 WebP。人物摆位暂不随剧情移动；次日后果由对白、说明与记录反馈。雨声由浏览器合成，字体使用系统中文字体。

这是单个下午及次日的静态剧情切片，没有完整五日故事、夜间走访、人物移动、自由输入、实时大模型或持久存档。刷新会重新开始。城市制度与 AI 同事的生活均为虚构设定。自动测试只能验证交互和分支，不能替代真实玩家对人物与主题的理解。
