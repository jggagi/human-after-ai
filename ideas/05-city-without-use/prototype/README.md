# 《无用之城》原型入口

**当前状态：尚无可运行原型，未选择引擎。**

## 首个切片候选

职业介绍所的一天、两位来访者、一次夜间走访，以及 AI 同事的一次合理拒绝。

候选试玩长度为 15–20 分钟，仅用来控制设计范围，不是工期或实现承诺。先用纸面、对白表或静态交互验证；技术选择服从叙事需要。

## 原型需要验证

- [ ] 两位来访者不能被同一种“重新变得有用”方案合理解决。
- [ ] 尊重某个人不接受安排，是可理解的完整选择，而非未完成任务。
- [ ] 没有就业率、幸福分数或统一人生价值分数充当最终裁判。

## 本阶段不做

不搭通用游戏引擎，不做开放世界，不接实时大模型，不做账号、云服务、付费、素材流水线或完整存档系统。临时素材可用占位文字和简单形状；正式外部素材需记录来源与使用条件。

## 开始实现时补充

在此记录所选技术及理由、启动命令、可玩范围、已知限制、试玩记录与结果。只有实际运行过后才标记“可运行”。不要为满足目录存在而写空项目或未经测试的启动指令。
