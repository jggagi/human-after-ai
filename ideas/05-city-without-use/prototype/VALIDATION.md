# Demo 验证

2026-10-03；本地 Python HTTP 服务，环境已有 Chromium + Playwright 实际运行。

## 本轮问题与修订

玩家反馈：开头难分清人物、背景与关系；试玩像处理琐事，不清楚故事想表达什么。

保留逐个出场的人物卡和随时查阅的关系介绍。重写主线为三个必经冲突：自动服务完成借用后许立的失落；丁禾质疑“未安置”标签并拒绝被继续匹配；周行面对自己失去岗位的担心。减少标签、搬箱、排班和移交操作。玩家先回应两个独立愿望，再替自己做选择。

## 实际运行结果

六条完整路线均通过，覆盖三种开场、三种许立方案、三种丁禾回应与三种周行个人选择。每条路线都经过三个核心冲突，看到对应的次日后果，并完成拉开椅子的最后动作。

验证了：两组可选追问；确认前方案不进入记录；改谈后正确保存新方案；丁禾拒绝岗位后周行停止匹配且不记为失败；丁禾不会自动成为值班者；继续求职、休息和与澄见面的记录互相独立；结尾反映两个后续选择；重玩清空旧决定。

人物介绍顺序、姓名查看人物卡、物件观察、历史记录、弹窗暂停故事输入、取消重启、数字键选择和合成雨声开关通过。资源请求无失败，浏览器无 JavaScript 运行错误。

检查了 1440px 桌面及 390px、320px 手机；无横向溢出，选择按钮达到触摸高度。桌面和 390px 手机的 200% 文本放大通过。已实际查看桌面标题、结尾与手机的丁禾冲突截图。

## 未验证的部分

本轮新剧情尚未得到真实玩家的再次试玩反馈。人物可信度、主题是否更易理解、情感强度和阅读时长仍待验证。没有把分支测试通过等同于这些创作目标已经实现。

场景图与人物摆位为静态美术，人物离开和次日到来由文字反馈；没有实现完整五日故事或夜间走访。
