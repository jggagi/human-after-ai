## 核心问题

失去工作的必要性之后，人能否不再凭“有用”获取存在资格？

## 候选交互循环

接待来访者 → 走访真实生活 → 理解各自需求 → 提供帮助或尊重不被安排 → 决定介绍所的未来。

以上内容来自初始提案，不应被当作作者已经批准的结论。角色、故事走向与机制需要在打磨中接受反例和试玩检验。

## 当前试玩提案

周行替居民找了六年工作，周五自己的岗位也将结束。最后两位来访者的愿望不同：许立想继续工作、被人需要，丁禾今天不想求职。自动服务已经满足借用需求，周行惯用的“未安置”记录却把不工作当成未完成的事。

玩家回应许立的愿望，面对丁禾的拒绝，再决定自己的求职单如何继续。继续工作、暂时休息和维持关系都有具体后果，没有统一价值评分。最后的动作是让一个不找工作的人坐下。

以上为根据“人物难辨认、像处理琐事、主题不清楚”反馈重写的可玩提案，尚未获得再次试玩确认。网页使用原有私有访问范围：[试玩《最后两份记录》](https://city-without-use-demo.jggagi.chatgpt.site)。
